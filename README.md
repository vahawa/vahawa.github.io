# BVG Abfahrten Express

Echtzeit-Abfahrtsmonitor für den Berliner Nahverkehr (BVG/VBB).

**Live:** [vahawa.github.io](https://vahawa.github.io/)

## Features
- GPS-basierte Haltestellenerkennung
- Echtzeit-Abfahrten via [Transitous](https://transitous.org/) (MOTIS, offene VBB-GTFS/GTFS-RT-Daten)
- Linien-Badges in den offiziellen VBB-Linienfarben
- Relative Abfahrtszeit („jetzt" / „X min"), aktualisiert alle 10 s
- Haltestellenfilter, Radius- und Anzahl-Einstellungen
- Auto-Refresh alle 30 s, sofortiger Refresh beim Öffnen aus dem Hintergrund
- Dark/Light Mode (System)
- Installierbar als Home-Screen-App (iOS/Android)
- Komplett client-seitig: kein Backend, keine Accounts, kein Tracking

## Daten
[Transitous](https://transitous.org/sources/) — community-betriebener Routing-Dienst auf Basis offener Fahrplandaten (VBB), nicht-kommerzielle Nutzung.
